Privacy Policy

Last Updated: October 10, 2026 • Neal Frazier Tech (@1nc0gn30) • NullAI Platform

1. Zero Remote Telemetry & No Cloud Snooping

Agent Budget Sentinel was architected from inception to respect sovereign engineering privacy. Neither the web cockpit nor the Python runtime transmits telemetry, analytics beacons, system fingerprints, model prompts, API tokens, or spending figures to any external remote servers.

2. Local Storage & In-Memory Operation

Any configuration preferences, simulation states, or license verification keys are stored strictly inside your local browser (localStorage) and within your designated local SQLite file (budget.db). You may purge this data at any moment with a single click.

3. Payment Processing Data

When purchasing a Pro license, transactions are processed directly by our payment partners: Stripe Inc. for card payments and DePay AG for on-chain cryptocurrency transactions. Neal Frazier Tech never stores, processes, or has access to your full credit card numbers or crypto private keys.

4. GDPR & CCPA Compliance

Because Agent Budget Sentinel operates without centralized user accounts or server-side databases of personal data, we do not monetize, sell, or profile user information.

5. Inquiries

If you have questions regarding this Privacy Policy, please reach out directly to Neal Frazier at support@nealfrazier.tech.
