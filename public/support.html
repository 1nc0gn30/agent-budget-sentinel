Frequently Asked Questions

How does Agent Budget Sentinel intercept runaway loops?

The tool runs an inline micro-proxy on port 8111. When your agent makes an OpenAI or Anthropic API call, Agent Budget Sentinel analyzes the prompt tokens, computes real-time pricing against our model database, and verifies the current spend against your hard ceiling and velocity threshold. If an anomaly or overage is detected, it trips in under 1ms and returns HTTP 429, instantly killing the infinite loop.

Does it require external dependencies or internet access?

Zero external pip dependencies. The core server, SQLite storage, token pricing calculator, and circuit breaker proxy use only the Python standard library. The web interface operates client-side with offline resilience.

How do I activate my Pro lifetime license?

Click "Have a key? Activate" in the header or sales banner, enter your Stripe checkout receipt email or transaction ID, and your browser will permanently unlock all FinOps and multi-agent fencing capabilities. You can also append ?licensed=true to your URL.
